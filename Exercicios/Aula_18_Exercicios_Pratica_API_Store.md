## Exercício 1 — Checklist técnico final ✅

Revise seu projeto e marque se está funcionando:

```text
[ ] POST /usuarios
[ ] POST /login
[ ] GET /perfil
[ ] GET /produtos
[ ] GET /produtos/:id
[ ] POST /produtos
[ ] PUT /produtos/:id
[ ] DELETE /produtos/:id
[ ] POST /pedidos
[ ] GET /meus-pedidos
[ ] GET /pedidos/:id
[ ] PATCH /pedidos/:id/status
```

Se alguma rota falhar, corrija antes de publicar.

## Exercício 2 — Gravar explicação do projeto 🎥

Grave um vídeo de 3 a 5 minutos explicando:

```text
1. O que é o projeto
2. Quais tecnologias usou
3. Como funciona o login
4. Como funciona a permissão de admin
5. Como funciona o pedido
6. Como rodar o projeto
7. Onde está o deploy
```

Esse vídeo pode ser usado como apoio no LinkedIn ou em processos seletivos.

## Exercício 3 — Publicar no LinkedIn 💼

Faça uma publicação apresentando o projeto.

Inclua:

```text
- nome do projeto
- tecnologias usadas
- principais funcionalidades
- o que você aprendeu
- link do GitHub
- link da API online
```

Objetivo: transformar o projeto em vitrine para recrutadores e outros devs.
