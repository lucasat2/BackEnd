## Exercício 1 — Pensando entidades de uma loja 🛒

Imagine que você vai criar uma API para uma loja online.

Liste 3 entidades principais.

Para cada entidade, escreva pelo menos 4 campos.

Exemplo:

```text
Entidade: Produto
Campos:
- nome
- preco
- categoria
- estoque
```

## Exercício 2 — Plataforma de cursos 🎓

Imagine uma API para uma plataforma de cursos.

Crie as entidades:

```text
Aluno
Curso
Matrícula
```

Para cada uma, defina os campos principais.

Exemplo:

```text
Aluno:
- nome
- email
- ativo
```
