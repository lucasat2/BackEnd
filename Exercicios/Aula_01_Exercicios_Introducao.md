## Exercício 3 — Pedido com frete grátis

Crie um arquivo:

```text
exercicio3.js
```

Crie:

```jsx
const produto = "Mouse Gamer";
const preco = 120;
const quantidade = 3;
```

Calcule o total.

Depois crie uma regra:

```text
Se o total for maior ou igual a 300, mostrar: Frete grátis.
Caso contrário, mostrar: Frete pago.
```

Exemplo esperado:

```text
Produto: Mouse Gamer
Total: 360
Frete grátis.
```
