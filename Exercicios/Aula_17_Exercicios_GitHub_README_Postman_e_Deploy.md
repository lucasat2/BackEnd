## Exercício 1 — Criar README do projeto 📄

Crie um `README.md` com:

```text
nome do projeto
descrição
tecnologias usadas
funcionalidades
como rodar localmente
variáveis de ambiente
rotas principais
link do deploy
```

Use uma linguagem clara, como se outro programador fosse rodar seu projeto.

## Exercício 2 — Criar collection no Postman 🧪

Crie uma collection chamada:

```text
API Store Node.js
```

Inclua pelo menos estas rotas:

```text
POST /usuarios
POST /login
GET /perfil
GET /produtos
POST /produtos
PUT /produtos/:id
DELETE /produtos/:id
POST /pedidos
GET /meus-pedidos
PATCH /pedidos/:id/status
```

Depois exporte a collection.

## Exercício 3 — Fazer deploy da API 🌐

Publique sua API em uma plataforma de deploy.

Depois teste:

```text
GET /produtos
POST /usuarios
POST /login
GET /perfil
```

Entrega esperada:

```text
link do GitHub
link da API online
print da API funcionando
collection do Postman
```
